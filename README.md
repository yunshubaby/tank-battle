# Tank Battle (坦克大战)

A classic tank battle game built with pure HTML5 Canvas and JavaScript.

## How to Play

- **W A S D** or **Arrow Keys** — Move your tank
- **Space** or **J** — Shoot bullets
- **P** — Pause / Resume

## Game Rules

- Destroy enemy tanks (red) to earn points
- Each kill gives 100 points
- Brick walls can be destroyed by bullets
- Steel walls are indestructible
- You have 3 lives — don't get hit!
- Destroy 20 enemy tanks to win
- Enemies get faster and more numerous as you progress

## Run Locally

Just open `index.html` in any modern browser. No dependencies required.
